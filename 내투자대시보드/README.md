# 개인 투자 대시보드

증권사 앱이 안 보여주는 것을 보는 **단일 HTML 대시보드**입니다. `SPEC.md`를 그대로 구현했습니다.

- **진짜 수익률** — 입출금에 오염되지 않은 TWR·XIRR
- **환율 효과 분리** — 수익 중 종목 기여분과 원/달러 기여분
- **복리 시각화** — 목표 수익률별 미래 자산 궤적

## 파일

```
내투자대시보드/
├── 대시보드.html          ← 산출물 (SPEC §6대로 라이브러리를 CDN에서 로드)
├── 대시보드_오프라인.html   ← 위와 동일하나 라이브러리를 파일 안에 내장 (인터넷 0% 필요)
├── 투자원장.xlsx          ← 사용자가 관리하는 실제 원장 (직접 준비, git에는 올리지 않음)
├── 투자원장_샘플.xlsx      ← 7년치 더미 데이터 (연별 7시트·약 150줄 · 거래 30건 포함)
├── 샘플원장생성.py         ← 위 샘플을 만드는 스크립트
└── SPEC.md                ← 설계 문서
```

> **`대시보드_오프라인.html`** 는 회사 PC 등 **인터넷·CDN이 막힌 환경**을 위한 단독 실행 버전입니다.
> 라이브러리(SheetJS·Chart.js)를 파일 안에 내장해, 더블클릭만으로 네트워크 없이 동작합니다.
> 계산·렌더·개인정보 처리(외부 전송 없음)는 두 파일이 완전히 동일합니다.

## 쓰는 법

1. **`대시보드.html` 을 브라우저에서 엽니다.** 파일을 더블클릭하면 됩니다. 설치·서버·빌드 필요 없음.
2. 화면에 **`투자원장.xlsx` 를 끌어다 놓거나** 클릭해서 선택합니다.
3. 끝. 6개 블록(핵심지표·성장곡선·월별수익률·리스크·자산구성·복리)이 채워집니다.

> 먼저 시험해 보려면 `투자원장_샘플.xlsx` 를 끌어다 놓아 보세요.
> 링크나 파일을 열 때 `?theme=` 없이도 시스템 다크모드를 따라갑니다.

## 눌러볼 수 있는 것들

| 어디서 | 무엇이 열리나 |
|---|---|
| 성과·구성 → 자산 구성 표의 **줄**, 또는 그래프 **조각** | 그 자산군만 담은 상세 패널 (연도별 평가액·순입금·수익률) |
| 숫자 옆 **`?`** | 그 지표가 무엇인지 — 클릭으로 고정되므로 휴대폰에서도 동작 |
| 시장지표 → **카드** | 그 지표의 뜻·기준일·출처 |
| 자산 성장 곡선 → **금액 / 수익률**, **전체 / 최근 N년** | 같은 데이터를 다른 축으로 |
| 차트 **범례** | 그 계열을 잠시 끄기 |
| **⌘K**(Ctrl+K) | 탭 이동 · 통화 · 테마 · 자산군 상세 · 용어 검색 |
| 개발기록 → 버전 **제목** | 그 버전의 변경 내용 펼치기 |
| 매매일지 → 거래 **카드** / 판정 **막대** | 그 거래의 계산식 전부 + 종목 가격 위 내 거래가 |
| 매매일지 → **안 했다면 / S&P에 넣었다면** | 판정 기준 바꾸기 |
| 매매일지 → **지금 / 2024년말 / 2023년말** | 그때 기준이었다면 판정이 어땠을지 되감기 |
| **숫자 카드** 아무거나 (총평가액·TWR·XIRR·목표·낙폭·심리·벤치마크·배당·복리·기준금리) | 그 지표가 무엇이고, 지금 값이 어떻게 나왔고, 어디까지 믿으면 되는지 |

닫기는 **Esc**. 상세 패널은 열려 있어도 인쇄에 끼어들지 않습니다.

## 리포트 (인쇄 · PDF)

머리 아이콘 → **전체 리포트**를 고르면 모든 탭이 한 문서로 나옵니다.

- **첫 장**은 애널리스트 리포트 조판입니다 — 제목 · 초록 · 주요 수치 표 · 출처 · 면책.
  초록과 표의 숫자는 화면에 이미 계산된 값에서만 가져옵니다.
- **본문**은 카드 상자를 걷어내고 괘선과 여백으로만 구분합니다. 종이에서는 그쪽이 읽기 쉽고,
  여러 장에 걸친 섹션에서 테두리가 종이 끝에 닿아 잘리는 것도 막습니다.
- 브라우저가 찍던 **날짜 머리글과 파일 경로 바닥글은 나오지 않습니다**(`@page` 여백을 0으로
  두고 좌우·위아래 여백을 직접 만듭니다). 그래도 보인다면 인쇄 대화상자의 *머리글/바닥글*
  체크를 꺼주세요.

## 개인정보 (§7)

- 모든 계산은 **브라우저 안에서만** 이뤄지고, 데이터는 **어디에도 전송되지 않습니다.**
- 라이브러리(SheetJS·Chart.js)만 CDN에서 불러옵니다. 한 번 연 뒤엔 인터넷을 꺼도 동작합니다.
- 엑셀은 **읽기 전용** — 대시보드가 원장 파일에 쓰지 않습니다.
- 실제 `투자원장.xlsx` 는 `.gitignore` 에 넣어 두었습니다. **개인 금융 데이터는 커밋하지 마세요.**

## 매매일지 — 그때 안 했다면?

원장에 **`거래일지`** 시트를 채우면 '매매일지' 탭이 켜집니다. 열은 다섯 개면 충분합니다.

| 거래일 (YYYY-MM) | 구분 | 티커 | 수량 | 단가 |
|---|---|---|---|---|
| 2021-11 | 매도 | TLT | 15 | 118.82 |

각 거래를 **하지 않았다면 지금 얼마였을지** 계산해 `잘한 선택` / `아쉬운 선택` 으로 판정합니다.

- **매도** → 계속 들고 있었을 때의 가치와 비교
- **매수** → 그 돈을 안 썼을 때(현금)와 비교
- 토글로 **S&P에 넣었다면** 기준으로 바꿀 수 있습니다 — 매매가 지수를 이겼는지

### 판정이 말하지 않는 것

- 매도 대금을 **무엇에 다시 넣었는지**는 반영하지 않은 단순 비교입니다.
- 세금·수수료는 **단가에 포함해 적은 만큼만** 반영됩니다.
- 기준가는 **'지금' 한 시점**입니다. 그래서 `지금 / 2024년말 / 2023년말` 토글을 넣었습니다 —
  기준 시점을 바꾸면 판정이 얼마나 뒤집히는지 직접 보라는 뜻입니다.
- 표본이 적으면 **결정 승률은 실력이 아니라 운**입니다.
- 종목의 **기준가를 못 찾으면 그 거래는 판정하지 않습니다**(추정하지 않음).

## 원장 양식 (SPEC §2)

`투자원장.xlsx` 시트는 **7장**뿐입니다 — `안내` · `연별스냅샷`(직접·연 1회) · `연말시장`(자동) · `연말보유`(자동·선택) · `거래일지`(직접·선택) · `배당`(선택) · `목표`.

직접 채우는 건 **`연별스냅샷`과 `목표`** 둘뿐입니다. 시장지표·Fear&Greed·미국 기준금리는
원장에 없고 **대시보드 HTML 안에 매일 자동으로 심깁니다**(원장 파일과 무관하게 매일 최신).
각 시트는 **4행이 헤더, 5행부터 데이터**입니다. 자산군은 6종만 사용하세요:
`해외주식` `해외ETF` `미국장기채` `MMF` `RP` `달러현금`.
