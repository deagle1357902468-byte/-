# 개인 투자 대시보드 — 설계 문서

## 0. 목적

증권사 앱이 보여주지 않는 것을 본다. 구체적으로 세 가지다.

1. **진짜 수익률** — 입출금에 오염되지 않은 TWR과 XIRR
2. **환율 효과의 분리** — 수익 중 얼마가 종목이고 얼마가 원달러인지
3. **복리의 시각화** — 목표 수익률별 미래 자산 궤적

사용자는 코드를 읽지 않는다. 모든 설명은 한국어 UI 텍스트로 화면에 있어야 한다.

## 1. 파일 구조

```
내투자대시보드/
├── 투자원장.xlsx     ← 사용자가 관리. 절대 수정하지 말 것 (읽기 전용)
├── 대시보드.html     ← 이 문서가 명세하는 산출물. 단일 파일.
└── SPEC.md
```

`대시보드.html`은 **단일 HTML 파일**이며 `file://`로 더블클릭해서 열린다. 로컬 서버, 빌드 도구, npm 설치가 필요해서는 안 된다.

## 2. 데이터 소스 — 투자원장.xlsx

엑셀은 순수 입력 저장소다. 모든 계산은 대시보드가 한다. `검산` 시트는 사용자 눈확인용이므로 읽지 않는다.

| 시트 | 데이터 시작 | 컬럼 |
|---|---|---|
| `월별스냅샷` | 5행 | A 기준월(YYYY-MM 문자열) · B 자산군 · C 통화(USD/KRW) · D 기말평가액 · E 당월순입금 · F 계좌 · G 비고 |
| `환율` | 5행 | A 기준월 · B USD/KRW 월말종가 |
| `벤치마크` | 5행 | A 기준월 · B S&P500 · C NASDAQ · D 다우존스 |
| `월말보유` | 5행 | A 기준월 · B 티커 · C 종목명 · D 수량 · E 종가USD · F 평가액USD · G 자산군 |
| `목표` | 5행 | A 목표명 · B 목표금액KRW · C 목표일 · D 월저축액KRW · E 가정연복리수익률 · F 비고 |

**자산군은 정확히 6종**: `해외주식` `해외ETF` `미국장기채` `MMF` `RP` `달러현금`

**파싱 규칙**
- 4행은 헤더. 5행부터 읽되 A열(기준월)이 비었으면 그 행은 건너뛴다.
- 예시 행이 남아 있을 수 있다. 비고에 "예시"가 포함된 행은 **경고만 띄우고 그대로 읽는다** (사용자가 지우도록 안내).
- 자산군이 6종에 없으면 화면 상단에 오타 경고 배너 + 해당 행 목록 표시. 조용히 무시하지 말 것.
- 환율이 없는 월은 계산에서 제외하고 경고.

## 3. 계산 정의

이 절의 수식을 그대로 구현한다. 임의로 바꾸지 말 것.

### 3.1 통화 환산

```
EV_krw(m,b) = 통화=="USD" ? EV(m,b) × fx(m) : EV(m,b)
EV_usd(m,b) = 통화=="KRW" ? EV(m,b) ÷ fx(m) : EV(m,b)
```
순입금 CF도 동일. `fx(m)`은 해당 월 환율.

### 3.2 월수익률 — Modified Dietz

```
r(m) = (EV(m) − EV(m−1) − CF(m)) / (EV(m−1) + 0.5 × CF(m))
```
- `EV(첫 달 이전) = 0`
- 분모 ≤ 0 이면 `null` (그 달은 차트에서 공백)
- KRW 기준·USD 기준·자산군별 모두 같은 공식

### 3.3 TWR

```
I(m) = I(m−1) × (1 + r(m)),   I(시작) = 100
누적 TWR = I(마지막)/100 − 1
연율화 TWR = (I(마지막)/100)^(12/n) − 1     (n = 관측 개월수)
```

### 3.4 XIRR

현금흐름 벡터를 만든다. 각 월 말일에 `−CF(m)`, 마지막 월 말일에 `+EV(마지막)`을 **추가로** 더한다.
NPV(r) = Σ CFᵢ / (1+r)^(dᵢ/365) = 0 이 되는 r을 **이분법**으로 찾는다 (구간 −0.99 ~ 10.0, 200회 반복). 뉴턴법은 발산하므로 쓰지 말 것.

### 3.5 환율 효과 분해

```
fx변동률(m) = fx(m)/fx(m−1) − 1
환효과(m)   = (1 + r_usd(m)) × (1 + fx변동률(m)) − 1 − r_usd(m)
```
검증: `r_krw(m) ≈ r_usd(m) + 환효과(m)`. 오차가 0.1%p를 넘으면 콘솔 경고.

누적 표시는 "누적 KRW 수익률 = 자산 기여분 X%p + 환율 기여분 Y%p" 형태로 KPI 아래 한 줄.

### 3.6 리스크 지표

월수익률 시리즈 r (KRW 기준 기본, 토글로 USD 기준) 에 대해:

| 지표 | 정의 |
|---|---|
| 연율화 변동성 | `stdev_표본(r) × √12` |
| MDD | `min( I(m)/cummax(I)(m) − 1 )` |
| 현재 낙폭 | `I(마지막)/max(I) − 1` |
| 언더워터 시리즈 | `I(m)/cummax(I)(m) − 1` (차트용) |
| 최대 회복기간 | MDD 저점 이후 전고점 회복까지 개월 수. 미회복이면 "진행 중 N개월" |
| 샤프비율 | `(연율화TWR − rf) / 연율화변동성` |
| 소르티노비율 | `(연율화TWR − rf) / (stdev(min(r − rf/12, 0)) × √12)` |
| 승률 | `count(r > 0) / count(r)` |
| VaR 95% (월간) | r 시리즈의 5% 분위수 (역사적) |
| CVaR 95% (월간) | 5% 분위수 **이하** 값들의 평균 |
| 베타 | `cov(r, r_bm) / var(r_bm)` |
| 추적오차 | `stdev(r − r_bm) × √12` |
| 정보비율 | `(연율화TWR − 연율화TWR_bm) / 추적오차` |
| 상관계수 | `corr(r, r_bm)` |

**무위험수익률 rf**: MMF·RP 자산군의 연율화 TWR을 쓴다. 사용자가 실제로 보유한 무위험 자산이므로 가장 정직한 기준이다. 해당 데이터가 없으면 3.0%를 쓰고 화면에 "가정치" 라벨을 붙인다.

관측치가 12개월 미만이면 연율화 지표 옆에 "표본 부족(n=N)" 배지를 단다. 숨기지 말고 표시할 것.

### 3.7 자산군 기여도

```
기여도(b, m) = w(b, m−1) × r(b, m)      w = 기초 시점 비중
기간 기여도 = Σ_m 기여도(b, m)
```
표시 예: "최근 12개월 총수익 14.2% 중 → 해외ETF 8.1%p · 장기채 3.4%p · 환율 2.7%p"

### 3.8 벤치마크

```
r_bm(m) = idx(m)/idx(m−1) − 1
```
**비교는 반드시 USD 기준 수익률끼리 한다.** 지수는 달러 표시이므로 KRW 기준 내 수익률과 비교하면 환율만큼 왜곡된다. KRW 토글 상태에서 벤치마크를 볼 때는 "USD 기준 비교" 안내 문구를 차트 하단에 넣는다.

### 3.9 복리 시뮬레이터

```
FV(t) = PV × (1+g)^t + PMT × 12 × ((1+g)^t − 1) / g        (g ≠ 0)
원금(t) = PV + PMT × 12 × t
복리분(t) = FV(t) − 원금(t)
```
- `PV` = 현재 총자산(KRW), `PMT` = 월저축액, `g` = 슬라이더 연복리수익률, `t` = 1..N년
- `g = 0`이면 `FV(t) = PV + PMT×12×t`
- 목표금액을 처음 넘는 t를 찾아 "목표 도달: 20XX년 (N년 후)" 표시

## 4. 화면 구성

세로 1열 스크롤. 카드 사이 여백 넉넉하게.

### 블록 0 — 헤더
- 좌: 제목 · 마지막 데이터 월 (`2026년 7월 기준`) · 관측 개월수
- 우: 엑셀 드롭존 (드래그앤드롭 + 클릭해서 파일 선택). 파일 로드 전에는 이 영역이 화면 전체를 차지하는 안내 화면.
- 하단 얇은 띠: **명언 1줄** (§5)

### 블록 1 — KPI 4칸
`총평가액` · `누적 TWR` · `XIRR` · `목표 진척률`
- 우상단에 **₩ / $ 토글**. 총평가액과 수익률 지표가 함께 전환된다.
- 각 KPI 카드에 물음표 아이콘 → 클릭 시 한 줄 설명 툴팁 (예: "XIRR — 입금 시점까지 감안한 내 돈의 실제 연수익률")
- 총평가액 아래 작게: 누적 손익 금액, 그리고 §3.5의 자산/환율 기여 분해 한 줄

### 블록 2 — 자산 성장 곡선
- 라인 2개: `평가액`(굵은 실선, 진한 색) · `누적 투입원금`(가는 점선, 회색)
- 두 선 사이를 **면으로 채운다.** 수익 구간은 초록 계열, 손실 구간은 붉은 계열. 이 벌어지는 면적이 이 차트의 전부다.
- 호버 시 그 달의 평가액·원금·차액 툴팁

### 블록 3 — 월별 수익률 막대
- 막대 2종 나란히: 내 수익률 · 선택된 벤치마크
- 상단에 **pill 버튼 3개**: `S&P 500` `NASDAQ` `다우존스`. 클릭하면 비교 대상 전환 (한 번에 하나).
- 양수 초록 / 음수 빨강
- 차트 하단 요약: 승률, 최고월, 최저월, 벤치마크 대비 초과수익 개월 수

### 블록 4 — 리스크 패널
- 상단: **언더워터 차트** — 0선 아래로 채워지는 영역 차트. MDD 지점에 마커와 라벨.
- 하단 **기본 노출은 4개만**: `MDD` `현재 낙폭` `연율화 변동성` `샤프`
- 나머지는 "자세히 ▾" 접힘 안에: `최대 회복기간` `소르티노` `월간 VaR 95%` `CVaR 95%` `베타` `추적오차` `정보비율` `상관계수`
- **12개 전부 항상 계산한다.** 접는 것은 화면 배치일 뿐이고, 사용자의 입력 부담은 지표 개수와 무관하다. 계산을 건너뛰지 말 것.
- 접힘 상태는 기본 닫힘. 펼침 여부는 기억하지 않는다.
- 벤치마크 의존 지표(베타·TE·IR·상관)는 블록 3에서 선택한 벤치마크를 따라간다.
- 각 카드에 물음표 툴팁 필수. 사용자는 FRM을 공부 중이므로 정의를 정확히 쓸 것.

### 블록 5 — 자산 구성
- 좌: **자산군 비중 도넛** (6종). 중앙에 총액.
- 우: **자산군별 성과 표** — 자산군 / 현재 평가액 / 비중 / 누적 TWR / 최근 12개월 기여도(%p)
- `월말보유` 시트에 데이터가 있으면 도넛 아래 **종목별 비중 도넛**을 추가로 렌더. 없으면 이 부분만 조용히 숨긴다.

### 블록 6 — 복리 시뮬레이터 + 목표
- 슬라이더 2개: `연복리 수익률` (0~20%, 0.5% 단위) · `월 저축액` (0~1000만원, 10만원 단위). 초기값은 `목표` 시트에서 읽는다.
- **누적 막대그래프**: x축 연도(현재~목표일+5년), 각 막대는 `원금`(아래, 회색) + `복리분`(위, 강조색)으로 쌓는다. 복리분이 시간이 갈수록 원금을 압도하는 게 눈에 보여야 한다. 이 블록의 존재 이유다.
- 목표금액 위치에 수평 기준선 + "목표 도달: 20XX년" 라벨
- 슬라이더 옆 실시간 숫자: 목표 도달 연도, 목표일 시점 예상 금액
- 하단에 목표 진척 게이지 (현재/목표)

## 5. 명언

헤더 하단 띠에 1줄. 페이지 로드마다 랜덤. 스타일은 얇은 이탤릭, 저채도 — 장식이지 주인공이 아니다.

`대시보드.html` 상단에 편집하기 쉬운 배열로 둘 것:

```js
const QUOTES = [
  { text: "Know what you own, and know why you own it.", by: "Peter Lynch" },
  { text: "The first rule of compounding: never interrupt it unnecessarily.", by: "Charlie Munger" },
];
```

주석으로 "여기에 좋아하는 문구를 추가하세요"라고 한국어로 남길 것. 임의로 명언을 지어내거나 출처가 불확실한 문장을 추가하지 말 것.

## 6. 기술 제약

- **단일 HTML 파일.** 빌드 없음, 서버 없음.
- 라이브러리는 CDN에서: SheetJS(xlsx 파싱), Chart.js(차트). 그 외 프레임워크 금지. React·Vue 쓰지 말 것.
- 폰트: 시스템 한글 폰트 스택 (`-apple-system, "Malgun Gothic", "Apple SD Gothic Neo", sans-serif`)
- 다크모드 대응 (`prefers-color-scheme`)
- 반응형은 최소한만. 데스크톱 1400px 기준으로 설계.

## 7. 금지 사항

- **데이터를 외부로 전송하는 코드를 넣지 말 것.** fetch·XHR·analytics·에러 리포팅 전부 금지. 개인 금융 데이터다.
- 엑셀 파일에 쓰지 말 것. 읽기 전용.
- 데이터가 없을 때 그럴듯한 가짜 숫자나 더미 차트를 그리지 말 것. 빈 상태는 빈 상태로 보여준다.
- 계산 실패를 조용히 0으로 대체하지 말 것. `null`로 두고 화면에 `—` 표시.
- localStorage 캐시는 기본 꺼짐. 체크박스로 사용자가 켤 때만 저장하고, 켜는 순간 "이 브라우저에 데이터가 저장됩니다" 안내를 띄운다.

## 8. 완료 기준

1. 원장 예시 데이터만 있는 상태에서 열어도 오류 없이 렌더된다.
2. 12개월치를 넣으면 6개 블록이 모두 채워진다.
3. ₩/$ 토글이 KPI와 성장곡선에 동시 반영된다.
4. 벤치마크 3개 전환이 블록 3과 블록 4의 관련 지표에 함께 반영된다.
5. 복리 슬라이더를 움직이면 막대그래프가 즉시 갱신된다.
6. 인터넷을 끊어도 (CDN 캐시 상태에서) 계산과 렌더가 동작한다.
