# 미국 증시 종가 기록 루틴 (나스닥 · S&P 500 · 다우)

매일 아침(한국시간 기준) 미국 3대 지수의 **종가를 자동으로 기록**하는 루틴입니다.

- **나스닥 종합지수** (Nasdaq Composite, `.IXIC` / `^IXIC`)
- **S&P 500** (`.SPX` / `^GSPC`)
- **다우존스 산업평균지수** (Dow Jones Industrial Average, `.DJI` / `^DJI`)

수집한 값은 저장소의 `data/` 폴더에 누적 저장됩니다.

## 📊 투자 대시보드 (웹)

수집한 데이터를 한눈에 볼 수 있는 **정적 웹 대시보드**가 포함되어 있습니다. 별도 빌드나
서버, 외부 라이브러리 없이 순수 HTML/CSS/JavaScript로 만들어졌고, 저장소의 `data/` 파일을
직접 읽어 렌더링합니다. 루틴이 매일 종가를 쌓을수록 대시보드도 함께 풍부해집니다.

**구성 요소**

- **지수 요약 카드** — 나스닥 · S&P 500 · 다우 각각의 종가, 전일 대비 변동(포인트·%), 당일
  고가/저가 범위 막대, 스파크라인, 시가/고가/저가/전일 종가.
- **지수 추이 비교 차트** — 기간 시작일을 0%로 맞춘 **상대 수익률**을 하나의 축에서 비교
  (마우스를 올리면 날짜별 값이 표시됩니다). 기간 선택: 7 · 30 · 90일 · 전체.
- **최근 기록 표** — 최신순으로 종가와 변동을 정리.
- **라이트/다크 테마**, 모바일 대응, 상승=빨강 / 하락=파랑(한국식, ▲▼ 화살표로 명확히 구분).

> 종가가 하루치만 있을 때는 추이 차트가 점으로 표시되고, **2거래일 이상 쌓이면 선 그래프**로
> 자동 전환됩니다.

### 보는 방법

로컬 파일을 직접 열면(`file://`) 브라우저 보안 정책 때문에 데이터 로드가 막힐 수 있으므로,
아래처럼 **작은 웹서버로 띄우거나 GitHub Pages에 배포**해서 보세요.

**① 로컬에서 미리보기**

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

**② GitHub Pages — 브랜치에서 바로 배포 (가장 간단)**

저장소 **Settings → Pages → Source: _Deploy from a branch_** 선택 후, 배포할 브랜치와
`/ (root)` 폴더를 지정하고 저장하면 됩니다. 잠시 후 `https://<사용자명>.github.io/<저장소>/`
에서 대시보드가 열립니다.

**③ GitHub Pages — Actions로 자동 배포**

저장소 **Settings → Pages → Source: _GitHub Actions_** 로 설정하면, `.github/workflows/pages.yml`
워크플로가 기본 브랜치 갱신 시(예: 매일 새 종가가 커밋될 때)마다 자동으로 재배포합니다.
Actions 탭에서 수동 실행(**Run workflow**)도 가능합니다.

> 팁: 링크에 `?theme=dark` 또는 `?theme=light` 를 붙이면 특정 테마로 바로 열 수 있습니다.

## 동작 방식

1. **스케줄러**: Claude 원격 루틴(Routine)이 매일 정해진 시각에 새 Claude 세션을 깨웁니다.
2. **수집**: 그 세션이 `scripts/fetch_indices.py`를 실행합니다.
   - 기본 소스: **CNBC** (한 번의 요청으로 세 지수 + 시장상태 + 전일종가)
   - 백업 소스: **Yahoo Finance** (CNBC 실패 시 지수별로 조회)
   - 둘 다 API 키가 필요 없고, 파이썬 표준 라이브러리만 사용합니다.
3. **기록**: `data/index_closes.csv`에 지수별로 한 줄씩 append 하고, `data/latest.json`을 최신 값으로 갱신합니다.
4. **커밋**: 세션이 변경분을 커밋하고 브랜치에 push 합니다.

## 실행 시각 ⏰

- **한국시간(KST) 오전 5시**에 실행합니다. → cron `0 20 * * 1-5` (UTC 20:00, 월~금)
- UTC 월~금 20:00 = KST 화~토 오전 5시로, **미국 정규장 5거래일의 종가를 각각 다음 날 아침에** 기록합니다. (주말은 새 종가가 없으므로 실행하지 않습니다.)

> ⚠️ **서머타임 주의**
> 미국 증시는 뉴욕시간 오후 4시에 마감합니다.
> - **미국 여름(서머타임, 대략 3~11월)**: 마감 = KST 오전 5시 → 5시 기록이 곧 **확정 종가**입니다. ✅
> - **미국 겨울(대략 11~3월)**: 마감 = KST 오전 6시 → KST 5시엔 **아직 장중**이라, 이때 기록되는 값은 마감 약 1시간 전의 장중 가격입니다.
>
> 그래서 각 행에는 `market_time_et`(가격 시각)와 `market_status`(시장 상태) 컬럼이 함께 저장됩니다. 값이 확정 종가인지 장중 스냅샷인지 항상 구분할 수 있습니다.
> 겨울에도 확정 종가만 남기고 싶다면 아래 "실행 시각 변경"을 참고해 KST 오전 7시(UTC 22:00)로 바꾸세요.

## 데이터 형식

`data/index_closes.csv` 컬럼:

| 컬럼 | 설명 |
|---|---|
| `captured_kst` | 기록 시각 (한국시간, ISO8601) |
| `index` | 지수 이름 |
| `symbol` | 심볼 (`.IXIC` / `.SPX` / `.DJI`) |
| `close` | 종가(마지막 가격) |
| `previous_close` | 전일 종가 |
| `change` | 전일 대비 변동 |
| `change_pct` | 전일 대비 변동률(%) |
| `open` | 시가 |
| `day_high` / `day_low` | 당일 고가 / 저가 |
| `market_time_et` | 가격의 미국 동부시간 기준 시각 |
| `market_status` | 시장 상태 (예: `REG_MKT`) |
| `currency` | 통화 (USD) |
| `source` | 데이터 출처 (`cnbc` / `yahoo`) |

`data/latest.json`은 가장 최근 실행 결과만 담습니다.

## 수동 실행 / 테스트

```bash
python3 scripts/fetch_indices.py
```

의존성 설치가 필요 없습니다. 실행하면 `data/`에 값이 추가됩니다.

## 실행 시각 변경

루틴의 cron 식을 바꾸면 됩니다 (UTC 기준). 참고 매핑:

| 원하는 KST 시각 | cron (UTC) | 비고 |
|---|---|---|
| 오전 5시 (현재) | `0 20 * * 1-5` | 여름=확정 종가 / 겨울=장중 |
| 오전 6시 | `0 21 * * 1-5` | 겨울 마감 시각 |
| 오전 7시 | `0 22 * * 1-5` | 사계절 확정 종가 (권장) |
| 매일(주말 포함) | `0 20 * * *` | 주말은 금요일 종가가 반복 기록됨 |

Claude에게 "루틴 실행 시각을 KST 오전 7시로 바꿔줘"처럼 말하면 변경해 드립니다.

## 참고

- 미국 공휴일에는 새 종가가 없으므로, 그날은 직전 거래일 종가가 그대로 기록될 수 있습니다.
- 지수 값은 정보 제공용이며, 데이터 출처(CNBC/Yahoo)의 지연·정정이 반영될 수 있습니다.
